GraphQL Authorization Fix Summary
=================================

PROBLEM: 401 Unauthorized errors when guest users try to list studios

ROOT CAUSE: Unauthenticated IAM role had NO policies attached

SOLUTION: Added IAM policy to grant guest users permission to query AppSync

FILES CHANGED:
1. amplify/backend.ts - Added IAM policy statement
2. src/app/services/studios.service.ts - Added fetchAuthSession() call
3. Documentation files

WHAT THE FIX DOES:
- Grants unauthenticated IAM role permission to execute GraphQL queries
- Allows guest users to read (list/get) studios from the API
- Maintains security: guests can only READ, not create/update/delete

DEPLOYMENT:
1. cd amplify && npx ampx sandbox
2. Wait for deployment
3. Test with: ionic serve
4. Deploy: git push

VERIFICATION:
- Check console: "[Studios Service] Auth session obtained: Yes"
- Check Network tab: GraphQL requests return 200 (not 401)
- Studios load from API (not just local data)

SECURITY:
✅ Guests can: Read studios
❌ Guests cannot: Create, update, or delete studios
✅ Authenticated users can: Full CRUD operations

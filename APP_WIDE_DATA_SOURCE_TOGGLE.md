## Data Source Toggle Flow

### User Action
1. User clicks toggle button on Arts page
2. DataSourceService toggles between 'mock' and 'database'
3. New source saved to localStorage
4. BehaviorSubject emits new source

### Service Reaction
1. All services subscribed to `dataSource$` receive update
2. Each service calls its `loadFromAPI()` method
3. Method checks `dataSourceService.isUsingMockData()`
4. Loads from MockDataService or database accordingly
5. Updates local state and emits to subscribers

### UI Update
1. Components subscribed to service observables receive new data
2. UI re-renders with new data
3. Toast notification shows current source

## Implementation Pattern

All services follow the same pattern:

```typescript
constructor(
  private dataSourceService: DataSourceService,
  private mockDataService: MockDataService
) {
  // Initial load
  this.loadFromAPI();
  
  // Subscribe to changes
  this.dataSourceService.dataSource$.subscribe(() => {
    this.loadFromAPI();
  });
}

private async loadFromAPI(): Promise<void> {
  if (this.dataSourceService.isUsingMockData()) {
    // Load from MockDataService
    const mockData = this.mockDataService.getMockXXX();
    this.allItems = this.convertMockData(mockData);
    this.itemsSubject.next(this.allItems);
    return;
  }
  
  // Load from database
  const result = await this.client.models.XXX.list();
  // ... process and emit
}
```

## Benefits

### Development
- **Instant Data**: No need to seed database for testing
- **Offline Work**: Develop without backend connection
- **Consistent State**: Same mock data every time
- **Fast Iteration**: No API latency

### Testing
- **Predictable Data**: Known mock data for tests
- **Isolation**: Test UI without database
- **Edge Cases**: Modify mock data for edge cases
- **Performance**: Compare mock vs database speed

### Demos
- **Quick Setup**: Toggle to mock for instant demo
- **No Backend**: Demo without database access
- **Consistent**: Same data every presentation
- **Fallback**: Use mock if database is down
